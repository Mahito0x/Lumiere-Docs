Lumière's Join-to-Create system lets members spin up their own temporary voice channel just by joining a special "creation" channel. The channel is theirs to control — rename it, lock it, set a user limit — and it's automatically cleaned up when everyone leaves.

## The basic idea

1. An admin sets up one "Join to Create" channel.
2. A member joins that channel.
3. Lumière instantly creates a new voice channel for them and moves them into it.
4. The member now owns that channel and can customize it with `/voice` commands.
5. When the channel is empty, Lumière removes it automatically.
