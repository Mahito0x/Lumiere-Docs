## Setup (admin — Manage Channels)

| Command | Description |
|---|---|
| `/temp autosetup` | Quick setup with defaults |
| `/temp setup` | Manual setup |
| `/temp defaults` | Set defaults for new temp channels |
| `/temp edit` | Edit an existing Join-to-Create channel |
| `/temp delete` | Remove the Join-to-Create system |

## Channel owner controls

| Command | Description |
|---|---|
| `/voice rename` | Rename your channel |
| `/voice limit` | Set user limit |
| `/voice lock` / `/voice unlock` | Lock or unlock the channel |
| `/voice ghost` / `/voice unghost` | Hide or show the channel |
| `/voice claim` | Claim an abandoned channel |
| `/voice transfer` | Transfer ownership |
| `/voice invite` | Invite a user |
| `/voice permit` | Grant access to users/roles |
| `/voice reject` | Revoke access / kick users or roles |
| `/voice bitrate` | Set bitrate |
| `/voice nsfw` | Toggle NSFW |
| `/voice region` | Set voice region |
| `/voice request` | Ask to join a locked channel |
| `/voice status` | Set channel status message |
| `/voice game` | Auto-rename based on activity |
| `/voice panel` | Resend the control panel |
