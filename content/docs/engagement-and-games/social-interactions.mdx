---
title: Social Interactions
description: Hug, kiss, wave, and other quick social commands.
---

These commands post a fun reaction-style message toward another member, similar to interaction commands found on many Discord bots. Each one takes a single `user` option — who you're directing the action at.

| Command | Action |
|---|---|
| `/hug user` | Give someone a wholesome hug |
| `/kiss user` | Give someone a sweet kiss |
| `/slap user` | Slap someone silly |
| `/highfive user` | High five someone |
| `/poke user` | Poke someone annoyingly |
| `/bite user` | Bite someone |
| `/wave user` | Wave to someone |
| `/lick user` | Lick someone |
| `/pat user` | Give someone a gentle pat |

## Ratings and compatibility

```
/rate user
```

Rate someone in funny, lighthearted ways.

```
/ship user1 user2
```

Check compatibility between two different users, framed as a fun "shipping" percentage. You can't ship yourself with this one.
