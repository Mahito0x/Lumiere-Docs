## Guess the Number

| Command | Description |
|---|---|
| `/gtn hint` | Get a logical hint |
| `/gtn profile` | View your (or another player's) profile |
| `/gtn stats` | Server stats |
| `/gtn leaderboard` | Leaderboard |
| `/gtnadmin setup` | Admin dashboard |
| `/gtnadmin access` | Manage who can play |

## Trivia

| Command | Description |
|---|---|
| `/trivia play` | Answer a trivia question |
| `/trivia stats` | Leaderboards, personal stats, accuracy, streaks, speed |

## Board games

| Command | Description |
|---|---|
| `/minesweeper` | Play Minesweeper |
| `/tictactoe` | Challenge someone to Tic-Tac-Toe |
| `/memorygame` | Play the emoji memory game |

## Social interactions

| Command | Description |
|---|---|
| `/hug` `/kiss` `/slap` `/highfive` `/poke` `/bite` `/wave` `/lick` `/pat` | Direct a social action at another user |
| `/rate` | Rate someone |
| `/ship` | Check compatibility between two users |

## Fun extras

| Command | Description |
|---|---|
| `/meme` | Random Reddit meme |
| `/mamajoke` | Yo mama joke by category |
| `/urban` | Urban Dictionary lookup |
| `/anime` | MyAnimeList lookup |
| `/pixel` | Pixelate a profile picture |
| `/cap` | Rate the "cap" in a statement |
| `/mirror` | Slightly-wrong message repeat |
| `/kill` | Funny "elimination" |

None of the commands in this section require any special Discord permission — they're available to every member by default, unless your server's admins have restricted them via [`/system control`](/administration/module-management).
