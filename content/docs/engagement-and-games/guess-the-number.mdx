---
title: Guess the Number
description: A number-guessing game with hints, streaks, and a server leaderboard.
---

Guess the Number is a simple, addictive guessing game — Lumière picks a number in a range, and members try to guess it, with logical hints along the way to narrow things down.

All commands are grouped under `/gtn`.

## For members

### Get a hint

```
/gtn hint
```

Uses a logical hint to help narrow down the current answer.

### Your profile

```
/gtn profile
```

View your own GTN stats, or another player's.

### Server stats

```
/gtn stats
```

### Leaderboard

```
/gtn leaderboard
```

## For admins

Admin commands are grouped under `/gtnadmin`.

| Command | What it does |
|---|---|
| `/gtnadmin setup` | Open the admin dashboard for Guess the Number |
| `/gtnadmin access` | Manage who is allowed to play |
