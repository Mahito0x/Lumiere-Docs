---
title: Fun Extras
description: Memes, jokes, lookups, and other one-off fun commands.
---

| Command | What it does |
|---|---|
| `/meme` | Get a random meme from Reddit |
| `/mamajoke category` | Get a "yo mama" joke — choose Skinny, Stupid, Tall, or Ugly |
| `/urban term` | Look up a word or phrase on Urban Dictionary |
| `/anime search` | Look up an anime or manga series on MyAnimeList |
| `/pixel target` | Pixelate a user's profile picture |
| `/cap text` | Rate how much "cap" (nonsense) is in a statement |
| `/mirror text` | Repeats your message back... slightly wrong |
| `/kill target` | "Eliminate" someone in a funny, over-the-top way |

## A note on `/urban`

Urban Dictionary is a crowd-sourced, unmoderated dictionary — results can occasionally include content that isn't appropriate for all audiences. Use this command with that in mind, especially in servers with younger members.
