---
title: Glossary
description: Terms used throughout the Lumière documentation.
---

**Case** — A permanent record created automatically for every moderation action (ban, kick, mute, warn, strike). See [Cases](/moderation/cases).

**Strike** — A lighter-weight infraction that can automatically escalate to a mute, kick, or ban once a member crosses a set threshold. See [Strikes](/moderation/strikes).

**Conduct score** — A passive, ongoing measure of a member's behavior across slurs, swears, toxicity, and links. Doesn't take action on its own. See [Conduct Tracking](/moderation/conduct-tracking).

**Module** — A group of related features (e.g. Moderation, Community Tools) that can be enabled or disabled as a whole per server. See [Understanding Modules](/getting-started/understanding-modules).

**Persistent role** — A role that's automatically restored if a member leaves and rejoins the server. See [Persistent Roles](/roles-and-access/persistent-roles).

**Join-to-Create** — The system that automatically creates a personal voice channel for a member when they join a designated channel. See [Voice & Channels](/voice-and-channels/overview).

**Whitelist / Blacklist** (in `/system control`) — A whitelist restricts a command to only the listed roles/users; a blacklist restricts it to everyone *except* the listed roles/users. See [Module Management](/administration/module-management).

**Backup ID** — The unique identifier assigned to a server backup when it's created, used in every other backup command. See [Server Backups](/server-backups/overview).

**Template** (backup) — A backup that's been published publicly so other servers can apply it as a starting structure. See [Templates](/server-backups/templates).

**Lumière Plus** — The optional paid tier that raises limits and unlocks additional capabilities beyond the free tier. See [Free vs Plus](/free-vs-plus/overview).
