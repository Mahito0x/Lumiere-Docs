---
title: Server Info
description: Look up details on users, roles, channels, emoji, and the bot itself.
---

All commands are grouped under `/info` and are available to everyone — no special permission needed.

| Command | What it shows |
|---|---|
| `/info user` | A member's profile and server status |
| `/info server` | A detailed look at the server — member counts, channels, roles, boost status, and more |
| `/info bot` | Technical information about Lumière itself — uptime, latency, version |
| `/info role` | Details about a specific role — color, permissions, member count, position |
| `/info channel` | Details about a specific channel — type, topic, permissions, creation date |
| `/info emoji` | Information about a custom server emoji |
| `/info avatar` | View a member's avatar in full size |
| `/info banner` | View a member's profile banner |
| `/info permissions` | View a member's effective permissions in the server |

These are diagnostic and reference tools — reach for `/info permissions` or `/info role`, for example, when you're trying to figure out why a role or permission isn't behaving the way you expect.
