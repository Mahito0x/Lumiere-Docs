---
title: Commands
description: Full command reference for Stats & Leaderboards.
---

| Command | Description | Permission |
|---|---|---|
| `/stats user` | View detailed stats for yourself or another member | None |
| `/stats leaderboard` | View server leaderboards (chatters, voice, engagement) | None |
| `/stats channel` | View channel-specific statistics | None |
| `/stats server` | View overall server analytics | None |
| `/stats heatmap` | View server activity patterns by time | None |
| `/stats privacy` | Manage your stats privacy settings | None |
| `/stats ignore` | Manage ignored channels/roles for stats | Manage Server (for server-wide scope) |
| `/stats reset` | Reset your personal stats data | None |
| `/stats reports` | Configure weekly stats reports | None |
