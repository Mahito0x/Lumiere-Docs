## Auto-roles on join

| Command | Description |
|---|---|
| `/autorole set` | Configure roles assigned on join |
| `/autorole delay` | Set anti-raid assignment delay |
| `/autorole conditions` | Set min account age / no-existing-roles conditions |
| `/autorole filter` | Manage who's included or ignored |
| `/autorole toggle` | Turn join/sync features on or off |
| `/autorole test` | Preview what roles a member would get |
| `/autorole config` | View current configuration |
| `/autorole delete` | Remove auto-roles from the config |

## Persistent roles

| Command | Description |
|---|---|
| `/persistrole toggle` | Enable/disable persistence for up to 5 users |
| `/persistrole clear` | Remove all persistent roles for a user |
| `/persistrole view` | View persistent roles (user or server-wide) |
| `/persistrole list` | List persistent roles for a specific user |
| `/persistrole server` | Enable/disable the feature server-wide |

## Temporary roles

| Command | Description |
|---|---|
| `/temprole add` | Assign a temporary role |
| `/temprole extend` | Add time to an active temp role |
| `/temprole remove` | Remove a temp role early |
| `/temprole expire` | Trigger immediate expiry |
| `/temprole list` | List active temp roles |
| `/temprole info` | View details on a specific temp role |

## Bulk role management

| Command | Description |
|---|---|
| `/massrole assign` | Assign a role to Members/Bots/Everyone |
| `/massrole unassign` | Remove a role from Members/Bots/Everyone |
| `/massrole sync` | Assign role to anyone missing it |
| `/massrole preview` | Dry-run an assign or unassign |

## Join-date roles

| Command | Description |
|---|---|
| `/joinrange assign` | Assign a role by join-date range |
| `/joinrange remove` | Remove a role by join-date range |
| `/joinrange preview` | Dry-run an assign or remove |

All commands in this section require **Manage Roles**.
