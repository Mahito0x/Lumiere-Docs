Lumière is a Discord bot built to run your server end to end — moderation, roles, voice channels, community tools, games, stats, and full server backups, all in one bot.

This site covers every command Lumière has, written for two kinds of readers:

- **Members** — if you just want to know what a command does and how to use it.
- **Server admins** — if you're setting features up, configuring permissions, or managing the bot for your whole server.

Most pages are split so you can jump straight to the part that applies to you.

## Where to start

- New to Lumière? Start with [Getting Started](/getting-started/introduction).
- Setting up moderation? Go to [Moderation](/moderation/overview).
- Looking for a specific command? Check the [Command Index](/reference/command-index).
- Something not working? See [Troubleshooting](/troubleshooting/common-issues).

## How this documentation is organized

Each feature area (Moderation, Roles & Access, Community Tools, and so on) follows the same shape:

1. **Overview** — what the feature does and why you'd use it.
2. **Feature pages** — one page per capability inside that area, written in plain language.
3. **Commands** — a full table of every command in that area, with what each option does.

If a feature has parts that only work for admins (like setup or configuration), that's called out clearly on the page — you don't need to guess.

## Free vs Lumière Plus

Some features are available to every server for free, and some are part of **Lumière Plus**. Wherever a command or feature is Plus-only, you'll see a clear label on the page. For the full breakdown, see [Free vs Plus](/free-vs-plus/overview).
