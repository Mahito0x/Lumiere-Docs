This section covers the everyday features members interact with directly — status indicators, birthdays, sticky info messages, counters, a counting game, and reaction-based highlight boards.

## What's in this section

| Page | What it covers |
|---|---|
| [AFK Status](/community-tools/afk-status) | Let others know you're away, and get pinged mentions when you're back |
| [Birthdays](/community-tools/birthdays) | Birthday announcements, countdowns, and time capsules |
| [Sticky Messages](/community-tools/sticky-messages) | Keep an important message pinned to the bottom of a channel |
| [Counters](/community-tools/counters) | Live-updating channel name counters (member count, and more) |
| [Counting Game](/community-tools/counting-game) | A collaborative number-counting game with streaks and modes |
| [Highlight Boards](/community-tools/highlight-boards) | Reaction-based "best of" boards for great messages |
