## For members

### Set your birthday

```
/birthday set
```

Opens a guided flow to set your birth date for announcements and celebrations.

### Control your privacy

```
/birthday privacy
```

Toggles whether your age and zodiac sign are visible to others when they view your birthday.

### View a birthday

```
/birthday view user
```

Leave `user` empty to view your own.

### Remove your birthday

```
/birthday remove
```

### Upcoming birthdays

```
/birthday upcoming
```

Shows what's coming up next in your server.

### Countdown to your birthday

```
/birthday countdown
```

### Server birthday stats

```
/birthday stats
```

### Birthday leaderboard

```
/birthday leaderboard
```

Ranks members by how many birthday wishes they've received.

### Get reminded about someone else's birthday

```
/birthday remind user
```

Sends you a DM reminder as their birthday approaches.

### List every registered birthday

```
/birthday list
```

### Birthday matchmaker

```
/birthday matchmaker
```

Finds the members in your server whose birthday is closest to yours — a fun way to discover birthday twins.

### Time capsules

```
/capsule write
```

Write a note to your future self, sealed until your next birthday.

```
/capsule read
```

View any time capsules that have unlocked.

## For admins

Admin commands are grouped under `/birthdays` and require **Manage Server**.

| Command | What it does |
|---|---|
| `/birthdays config` | Configure the birthday system for your server |
| `/birthdays zodiac` | Configure zodiac sign roles |
| `/birthdays edit member` | Override or purge a member's birthday |
| `/birthdays announce member` | Manually trigger a birthday announcement |
| `/birthdays settings` | View current configuration |

### Blacklist

```
/blacklist add
/blacklist remove
/blacklist list
```

Excludes specific users or roles from the birthday system entirely (also requires **Manage Server**).
