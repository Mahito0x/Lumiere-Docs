## AFK

| Command | Description | Permission |
|---|---|---|
| `/afk set` | Set your AFK status | None |
| `/afk status` | Check your AFK status | None |
| `/afk cancel` | Cancel AFK manually | None |
| `/afkadmin clear` | Clear one member's AFK | Manage Server |
| `/afkadmin clearall` | Clear everyone's AFK | Manage Server |
| `/afkadmin list` | List all AFK members | Manage Server |
| `/afkadmin panel` | Server-wide AFK settings | Manage Server |
