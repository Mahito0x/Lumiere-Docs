---
title: Upgrading Your Server
description: How to move your server to Lumière Plus.
---

Lumière Plus is purchased and managed per server, not per Discord account. Any active subscription applies to the whole server, so every member benefits — not just whoever paid.

## How to upgrade

1. Go to [lumierelabs.xyz](https://lumierelabs.xyz) and sign in with Discord.
2. Select the server you want to upgrade.
3. Choose a Plus plan and complete checkout.

Plus features activate automatically once payment goes through — there's no separate setup command needed in Discord.

## Who can upgrade a server

Anyone with **Manage Server** permission on the target Discord server can start a subscription for it. You do not need to be the server owner.

## After upgrading

Run `/system control` if you'd like to check that Plus-only modules are visible, or just use the relevant commands directly — Lumière automatically recognizes an active subscription.

For anything about payment methods, invoices, or cancelling, see [Billing & Subscription](/free-vs-plus/billing-and-subscription).
