Lumière is free to add and use. **Lumière Plus** is an optional paid tier that raises limits and unlocks extra capabilities on top of the free feature set — it's not a separate bot, and nothing you already use gets taken away if you don't upgrade.

## How this is marked throughout the docs

Wherever a command or setting is Plus-only, you'll see a label like this directly on the page:

> **Lumière Plus** — this feature requires an active Plus subscription for your server.

If a page doesn't have that label, the feature is available on the free tier.

## Where things typically differ

Plus generally raises **limits** rather than gating entire features — things like the number of active backups you can keep, the number of counters or boards per server, or how far back stats history goes. A small number of advanced tools (like certain backup and template features) are Plus-only outright.

For the current, exact list of what's free vs Plus — including pricing — see the live comparison at [lumierelabs.xyz/pricing](https://lumierelabs.xyz/pricing). That page is the source of truth; this documentation focuses on how each feature works once you have access to it.
