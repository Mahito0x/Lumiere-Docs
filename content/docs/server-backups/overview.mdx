Lumière can capture a full snapshot of your server — channels, roles, permissions, and structure — and let you restore it later, compare it against your current setup, or hand it to another server as a starting template.

Every command in this section requires **Administrator**, since restoring a backup can significantly change a server's structure.

## A word of caution

Restoring a backup changes your server's actual structure — channels, roles, and permissions can be created, modified, or removed to match the backup. Always run `/backup compare` before `/backup load` so you know exactly what will change. See [Restoring a Backup](/server-backups/restoring-a-backup).
