### Is Lumière free?

Yes — Lumière is free to add and use. [Lumière Plus](/free-vs-plus/overview) is an optional paid tier that raises limits and adds extra capabilities on top of the free feature set.

### Do I need to be the server owner to configure Lumière?

No. Most setup and admin commands require **Manage Server** or a specific Discord permission (like **Manage Roles** or **Ban Members**), not server ownership. See [Permissions & Access](/administration/permissions-and-access).

### Can I turn off features I don't want?

Yes. Every module and command can be disabled per server through [`/system control`](/administration/module-management).

### Does deleting a backup delete my actual server?

No. Backups are snapshots stored separately from your live server. Deleting a backup only removes that stored snapshot — your server itself is untouched. See [Server Backups](/server-backups/overview).

### Can members opt out of stats tracking?

Yes, at any time, with `/stats privacy`. See [Your Stats](/stats-and-leaderboards/your-stats#privacy).

### What happens to Plus features if I stop subscribing?

Your server keeps Plus access until the end of the current billing period, then returns to the free tier automatically. See [Billing & Subscription](/free-vs-plus/billing-and-subscription#what-happens-if-you-cancel).

### Where do I manage billing?

Entirely through the dashboard at [lumierelabs.xyz](https://lumierelabs.xyz) — not through Discord commands. See [Billing & Subscription](/free-vs-plus/billing-and-subscription).

### I can't find a command — where do I look?

Check the [Command Index](/reference/command-index) for a complete, searchable list of every command in Lumière.
